# 如流 · PhraseFlow

适用于 macOS 14 或更新版本，安装包同时包含 Apple 芯片与 Intel 版本。语音识别、校对、词库和修改记忆都在本机运行。听写无需联网。启动检查更新、安装新版或下载可选模型时会联网，不发送语音、定稿或词库。

## 开始听写

1. 打开安装镜像，将「如流」拖入「应用程序」，从那里打开。首次打开先设置听写权限，再选择是否保留文字、录音和改词记录。完成后如流常驻菜单栏。
2. 把光标放进输入框，按住 **右 ⌘ Command** 说话，松开就输入。也可以短按一次开始，说完再短按一次，定稿会写回原处。按 **Esc** 取消。只想按住说话，可在「设置 → 听写」关闭「短按切换持续听写」。没有听清语音时，悬浮窗会自行收起，不新增记录。
3. 关掉窗口不会退出应用。单击菜单栏声波图标可开始听写、复制上次定稿，或打开历史与设置。需要主窗口时，点「打开听写」或程序坞图标。

## 在其他应用中输入

在「设置 → 权限与记录」点「允许…」，按 Mac 的提示操作。麦克风用于听写，辅助功能用于在其他应用的光标处输入。返回应用后，权限状态会自动更新。需要更改已有选择时，点「打开设置」。

右 ⌘ 需要输入监控。未允许时暂用 Control–Shift–空格；允许后会自动切回右 ⌘。F6 和备用组合键不需要输入监控。

密码框不开始听写。若听写后光标已移动，或原应用没有可确认的输入位置，可在悬浮窗点「复制」。悬浮窗收起后，也可以点菜单栏图标，选「复制上次听写」。

## 整理和审阅

| 整理方式 | 对口述做什么 |
| --- | --- |
| 原样记录 | 保留语气词、重复和改口。 |
| 轻度整理 | 去掉卡顿和无意的重复。明确改口的时间按最后说的记。 |
| 精简口语 | 再去掉“我的意思就是说”这类套话。 |
| 分点整理 | 精简口语，按说出的步骤或要点分段。 |

所有听写模型都支持这四档。整理在本机完成，保留术语、否定和原来的顺序；数字与标点按惯例书写。

边说边断句，明确的用词更正会短暂显示为红删绿增。松开听写键后，结合前后文核对容易听混的词。两种写法都说得通时，保留原词供你选择。遇到轻声收尾或部分有歧义的短句，会用原声再次辨认；不按句意猜最后一个字。

听写页、历史记录和悬浮窗都可以直接点正文修改。按 **⌘↩** 或点「保存」提交，按 **Esc** 取消；普通回车换行。悬浮窗收起后，听写页仍保留本次定稿。

在听写页或悬浮窗保存，若原文和原光标位置都能核对，会同步替换刚输入的那一段；核对不上只更新本机定稿，可点「复制」。改历史记录只改本机。拿不准的写法会列在正文下，直接点候选就换，可撤销。想先审后发，在「设置 → 听写」打开「输入前审阅」。

### 重新听一遍原录音

对定稿不满意，在悬浮窗点「增强识别」。进度、改字和可选写法都留在原窗，不打断当前输入。悬浮窗收起后，点菜单栏图标，选「增强上次听写」即可调回。在听写页或历史页点「增强识别」，结果直接显示在所选正文旁。复听使用保留在本机的录音，无需重新说，也不会下载模型。

先听完整段，再带着前后文分句重听；已安装全精度模型时可与内置模型交叉核对。两次读音和上下文支持的改字会直接写回，保留原稿的分段，不会仅因标点不同改稿。有分歧时，点正文下的写法即可替换；点「撤销」可逐步恢复。

待审阅的结果只改草稿。悬浮窗和听写页会在原文、文档、输入框和光标都能核对时同步替换刚输入的文字；位置变化后只更新本机定稿。历史页只改选中的记录。只保留录音的历史可以临时查看和复制结果，不补存文字。复听期间手动改过的稿件不会被覆盖。

## 词表与记忆

- **内置词库**分为「生活与出行」「科学与技术」「人文与社会」。在首页可一键全部启用；点进分类可筛选主题。升级会沿用以前各类的选择，移除的词不会被重新打开。
- **朗读古诗文**不必切换模式或开启专业词包。「人文与社会」里可直接打开「诗词古文」或「成语歇后语」，也可搜篇名、作者或半句原文。朗读时，应用先听声音，再核对读音和相邻的原句；读到哪儿就记到哪儿。篇名、前后句和读音能互相印证时，定稿会纠正错词。还拿不准的写法留在正文下方；保存文字时也保留仍适用的候选，回到「历史」可以直接点选。移除某条原句或关闭「按语境校对用词」，它便不再参与校对。
- 搜索支持名称、常见误听、主题和部分外文品牌名。例如搜「奢侈品」「茶底」「电瓶车」或「Loewe」。点分类可缩小范围。外文名和中文名都能搜到同一条记录；听写保留说出的写法，不在两者之间自动翻译。 搜「海豚」也能分别找到动物和车型；只有完整车名才列为「比亚迪海豚」。
- **我的词库**可手动添加、导入，也可开启「收录常用词」。开启保存文字后，同一用词在最近 80 次有候选词的听写定稿中出现至少三次才收录；一段内重复只算一次，审阅以最后确认的内容为准。暂停后不再累计。已收录的词可编辑为手动词条、单独忘记或批量清空。只在本机保存词和使用次数，不回读旧历史，也不采集其他应用中的正文。常用词不会成为强制改写规则。
- **导入**支持 TXT、CSV、TSV、Rime `.dict.yaml`、macOS 文本替换 `.plist` 和 JSON。TXT 可用空格、换行、制表符、中英文逗号、顿号和分号分隔；多词短语加引号，如 `三支一扶，“Visual Studio Code” 海淀`。可在预览中选「每行一词」或「写作与读作」，确认后再加入选定的词库。
- **屏蔽词**是“不容易选中”，不是“不许显示”。把容易误听成的词加进名单，可降低它作为识别或校对候选的优先级。清楚说出的词仍照常显示、复制和输入，历史不因名单变化而改写。名单也支持批量导入。
- **修改记忆**默认开启。第一次亲手改词，写法只作备选。至少两段不同的录音都确认过同一写法，而且眼前这句话也有相符的用词，定稿时才可能自动采用。反复编辑同一条只算一次；两种写法都说得通时，保留原词，让你选。每段听写的第一遍识别都不加词语提示；定稿时，手动词条仍按你指定的写法整理。可在「设置 → 权限与记录」关闭记忆或忘记某一条。
- **关联连续听写**默认开启。在同一应用里，三分钟内接着说，可以参考上一段的话题或专名。关闭文字记录后不再关联。

## 长录音和历史

录音和识别分开处理。开启「保存录音」后，每五分钟在本机写完一节，历史中仍是一条连续记录，可依次回放。打开「缩短录音里的长静音」会缩短回放中超过四秒的近乎无声片段，保留两端；送去识别的声音始终完整。休眠会结束当前听写。

文字和录音分别保留，默认各保留最近 20 条。关闭保存只影响新记录。在历史中用 **↑ / ↓** 滚动正文；到边界后再按一次切换记录。

## 本地模型和悬浮窗

安装包只含「均衡听写」。其他模型在「设置 → 模型」中点「下载」，装好后点「使用」切换。所有模型均在本机识别。

| 模型 | 本机占用约 | 适合的用法 |
| --- | --- | --- |
| 均衡听写 | 169 MB，已内置 | 960 毫秒窗口，日常中文和中英混说。 |
| 快速听写 | 下载 134 MB，安装 169 MB | 480 毫秒窗口，短句优先出字。 |
| 长句听写 | 下载 134 MB，安装 169 MB | 1.92 秒窗口，首批文字稍晚。 |
| 全精度中英听写 | 下载 584 MB，安装 615 MB | 中英混说，使用更多内存。 |
| 普通话大模型 | 下载 598 MB，安装 771 MB | 主要说普通话，计算量更大。 |

「设置 → 悬浮窗」中可选六套配色与三种着色方式，调整宽度、字号和停留时间。点「在屏幕上预览」看实际尺寸；「恢复默认」只还原悬浮窗的外观和位置。默认青瓷磨砂，位于屏幕底部。拖动顶部横条即可定位，松开即记住。桌面会避开程序坞；全屏时可贴近显示器底边，也可在「大小与位置」中还原。音量波形、柔光和流光可分别关闭；动效遵循系统的“减少动态效果”。

## 更新与卸载

每次打开会在后台检查新版。听写时不会抢走光标，也不会自动下载。「设置 → 更新」显示新版大小和说明；点「下载并更新」后可看下载进度，完成正在进行的听写或修改后才重启。忽略只对当前版本有效，手动检查仍可重新选择。升级后的第一次打开会展示新版特性。

下载中断时，也可以用安装包手动更新。退出旧版「语音输入」，只将旧应用移到废纸篓，再把镜像里的「如流」拖入「应用程序」。不必删除记录、重设偏好或同时保留两份应用。

从「设置 → 更新 → 卸载如流」可选择仅将应用移入废纸篓，或连同文字、录音、词库、模型和设置一起删除。直接在访达中删除应用会保留本机资料。

## 从源码构建

使用含 macOS 26 SDK 或更新 SDK 的开发工具构建双架构应用。内置模型和运行组件按发布摘要校验；与当前版本一致的本地资源可用于离线重建。组件来源及许可见 `Resources/Licenses`。

本机自用：在源码目录运行 `bash 构建.command --local`，再运行 `bash 制作安装镜像.command --local`。如果电脑上有唯一的 Apple Development 签名，构建会沿用它，也可用 `DEVELOPMENT_ID` 指定。没有证书时，只生成固定的本机版：重复安装同一镜像不改变应用身份，重新编译的版本则可能需要重新授权。构建不会用不兼容的签名覆盖原产物。「如流（本机版）.dmg」未经公证，不作为公开发行包。

公开分发：设置 `DEVELOPER_ID`（Developer ID Application 签名身份）和 `NOTARY_PROFILE`（钥匙串中的公证配置），先运行「构建.command」，再运行 `bash 制作安装镜像.command --release`。应用和镜像均须通过签名、公证和系统检查，才会写出 `PhraseFlow.dmg`。首次打开确认和隐私授权由 macOS 管理。

未公证的候选镜像：构建与制镜均显式传入 `--preview`，生成 `PhraseFlow.dmg`，在 GitHub 上标记为预发布。签署更新前设定 `SPARKLE_TOOLS` 为 Sparkle 发行包的 `bin` 目录，然后运行 `bash 制作更新清单.command <镜像路径> <发布标签> <仓库根目录>`。同时上传同一文件的 `Shengru.dmg` 别名，供旧版更新。先核对两份下载的摘要，再发布 `appcast.xml`。更新签名与 Apple 公证独立。
